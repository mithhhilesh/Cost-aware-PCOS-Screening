INPUT OBSERVATIONS
==================

Source: the input schemas stored in the current artifacts/*.joblib export.
These are the exported training-data minimum and maximum values.
They are NOT clinical normal ranges, diagnostic thresholds, or hard input limits.
An input outside an observed range may still receive a prediction with a warning.
Separate cleaning rules may reject some values.

Definitions
-----------
Cycle length(days) means menstrual bleeding duration: the number of days
bleeding lasts during a period, not the interval between periods.
Cycle(R/I): code 2 = Regular; code 4 = Irregular.
Yes/No inputs: code 0 = No; code 1 = Yes.
